## SIAP phase-plane paper

The SIAP phase-plane paper is background machinery that should certainly be mentioned, but not emphasized in this talk.

## Final take-home message

The possible messages "susceptible recruitment is insufficient," "burnout is computable," and "SIRS changes the prediction" are not sufficiently clear as stated.

If we say "susceptible recruitment is insufficient," then we also need to say something like "but including decay of immunity can be sufficient, for example SARS-CoV-2," which is much clearer than "SIRS changes the prediction."

"Burnout is computable" is a poor message because burnout probability has always been computable via demanding simulations. The contribution here is a direct, convenient analytical formula for this probability for SIR and SIRS models. This changes the computation from something that may take days or weeks by brute-force simulation to something that can be computed in a second. The contour plots that provide insight would be far too demanding to create by brute-force simulation.
